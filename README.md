# NexusAgent Studio 🚀

Um editor de código com Agente de IA Local estilo Cursor/GitHub Copilot Workspace focado no Ubuntu Linux.

## Recursos
- 🐳 **Runner Docker Padrão**: Compilações e testes isolados em contêineres epêmeros.
- 🐙 **Copiloto de Repositório**: Ferramentas integradas para Git e GitHub (Issues, Branches, Commits, PRs).
- 🤖 **IA 100% Local**: Suporte a modelos locais via Ollama (`qwen2.5-coder`, `deepseek-r1`).
- 🛡️ **Modos Assistido vs. Autônomo**.

## Como Executar
1. Certifique-se de que o Docker e o Ollama estejam ativos.
2. Instale as dependências: `pip install -r requirements.txt`
3. Execute o app: `python3 app.py`
